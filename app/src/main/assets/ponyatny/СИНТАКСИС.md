# Язык «Понятный» — полное описание синтаксиса (версия 2.6)

«Понятный» — язык программирования с русскими словами. Программа — это текстовый файл `.pon` в кодировке UTF-8.
Компилятор переводит её в JavaScript, а из него может собрать отдельную программу `.exe` (Windows) или исполняемый файл (Linux).

## 1. Общие правила

- Одна команда — одна строка. Отступы не обязательны, но помогают читать код.
- Блоки (`если`, `пока`, `функция`, `класс` …) всегда заканчиваются словом `конец`.
- Комментарий — от `#` или `//` до конца строки.
- Служебные слова пишутся маленькими буквами или с большой первой буквы (`Если`, `если`).
- Язык умный и прощает мелкие опечатки в служебных словах (см. раздел 14а).
- Имена: буквы (любая кириллица — русская, украинская, белорусская … — и латиница), цифры, `_`; начинаются не с цифры. Длина имени — до 255 символов. `счёт` и `счет`, `Имя` и `имя` — разные имена.
- В одной части имени нельзя смешивать русские и латинские буквы: `сoк` с латинской `o` выглядит как `сок`, но это другое имя, поэтому компилятор такое запрещает и подсказывает правильное написание. Части, разделённые `_`, могут быть на разных алфавитах: `get_Имя` можно.
- Текст программы приводится к форме Юникода NFC, поэтому `й`, набранная как `и` + знак краткой, — та же буква `й`. «Совместимые» формы букв (например, лигатура `ﬁ`) в именах запрещены.
- Невидимые символы направления текста (U+202A–U+202E, U+2066–U+2069, U+200E, U+200F, U+061C) и невидимые символы нулевой ширины (U+200B–U+200D, U+2060, U+00AD) запрещены во всём тексте, включая строки и комментарии: через них код может выглядеть не так, как работает (атака Trojan Source, CVE-2021-42574). Если такой символ нужен в строке, пишите `\u{202E}`.
- Внутренние имена JavaScript (`constructor`, `prototype`, `__proto__`, `toString`, `call`, `apply`, `bind` и любые имена, начинающиеся с `__`) нельзя писать после точки и нельзя давать полям и функциям классов. Ключи словаря могут быть любыми строками.
- Внутри скобок `( )`, `[ ]`, `{ }` можно переносить строку.
- Нумерация элементов списков и строк начинается с 0; отрицательный номер считается с конца (`с[-1]` — последний).
- Служебные слова нельзя брать именами переменных, полей и функций. Часто мешает слово `в` (это проверка «есть ли в списке»): высоту называйте `высота` или `выс`, не `в`.

### Служебные слова

**Короткие формы — основные (с версии 2.3).** В примерах пишите коротко, в повелительном наклонении. Старые длинные слова работают как синонимы для совместимости:

| Основное (короткое) | Старое (синоним, работает) |
|---|---|
| `пиши "1"` | `напиши "1"` |
| `повтори 3 раз` | `повторить 3 раз` |
| `пробуй` | `попробуй` |
| `конст МАКС = 100` | `константа МАКС = 100` |

Слова `пиши повтори пробуй конст` теперь служебные — их нельзя использовать как имена переменных.

`пусть константа навсегда пиши если то иначе пока повторить раз для каждого из от до шаг функция верни конец и или не в истина ложь ничего стоп дальше попробуй ошибка как наконец брось выбор вариант когда класс наследует структура это себя родитель новый подключи затем`

Слова `каждого из от до шаг раз ошибка как наконец наследует` — особые только на своём месте, в других местах их можно использовать как имена.

**Новые слова версии 2.4** — особые только в начале команды (и только если дальше не идёт `=`, `(`, `.`, `[`), поэтому старые программы с такими именами работают как раньше:
`переменная делай перечисление интерфейс ленивая глобальная предупреди отладка убедись`, внутри класса — `общая скрытая абстрактная свойство`, после имени класса — `реализует`.

**Новые слова версии 2.5** — тоже только в начале команды (кроме выражений вроде `ждать`, `ссылка`, `размер`, `формат`): `метка`, `ярлык`, `иди` / `перейди` / `goto`, `поток` / `нить`, `асинхронная функция`, `с` / `используя` … `как`, `из` … `возьми`. Подробно — раздел 19.

Ещё у служебных слов есть синонимы и разные формы, а у некоторых — шуточные варианты (раздел 17).

## 2. Типы

| Тип | Примеры | `тип(x)` |
|---|---|---|
| число | `5`, `3.14`, `1_000_000` | `"число"` |
| строка | `"текст"`, `«ёлки»`, `“из Word”`, `"Привет, {имя}!"` | `"строка"` |
| логическое | `истина`, `ложь` | `"логическое"` |
| список | `[1, 2, 3]`, `[]` | `"список"` |
| словарь | `{"ключ": 1, имя: "Оля"}`, `{}` | `"словарь"` |
| функция | `функция(x) => x * 2` | `"функция"` |
| ничего | `ничего` | `"ничего"` |
| множество | `множество([1, 2, 2])` → `множество{1, 2}` | `"множество"` |
| объект класса | `Кот("Барсик")` | имя класса |

Дробные числа печатаются с запятой: `пиши 7 / 2` → `3,5`.
Ложными считаются `ложь`, `ничего`, `0` и пустая строка `""`; всё остальное — истина.

Тип можно указать (необязательно), тогда он проверяется:
```
пусть возраст: число = 12
функция площадь(a: число, b: число) -> число
    верни a * b
конец
пиши площадь(3, 4), возраст
```
Вывод: `12 12`.

Типы для указания: `число целое строка логическое список словарь множество функция ничего любое`, имена классов и интерфейсов. `целое` — число без дробной части (`пусть н: целое = 5`; `5.5` даст ошибку при выполнении).

## 3. Переменные и константы

```
пусть x = 5            # обычная переменная, её можно менять
x = x + 1
x += 2                 # также -=  *=  /=  %=
константа МАКС = 100   # имя нельзя переназначить
пусть навсегда дни = ["пн", "вт"]   # нельзя ни переназначить, ни менять внутри
пиши x, МАКС, дни
```
Вывод: `8 100 [пн, вт]`.

- `константа` запрещает `МАКС = …` (ошибка при компиляции).
- `пусть навсегда` запрещает и переназначение (при компиляции), и изменение содержимого (при выполнении): `дни.добавь("ср")` → «это значение объявлено «навсегда», его нельзя менять».
- Переменную нужно объявить через `пусть` до первого присваивания. Внутри блока можно объявить своё имя, оно видно только в этом блоке.

### Другие виды переменных (с версии 2.4)

```
переменная счёт = 0              # то же, что пусть (ещё: пускай, создай)
постоянная П = 3.14              # то же, что константа
пусть а, б = 1, 2                # несколько имён сразу
а, б = б, а                      # обмен значениями
пусть точка = [3, 4]
пусть x, y = точка               # справа список ровно из двух значений
пусть с = [""]
пусть т = {поле: ""}
с[0], т.поле = "a", "b"          # слева могут быть элементы и поля
функция посчитать()
    пиши "считаю"
    верни 10
конец
ленивая отчёт = посчитать()      # посчитается при первом обращении, один раз; менять нельзя
пиши "ещё не считали"
пиши отчёт
пиши отчёт
функция настрой()
    глобальная режим = "тихий"   # объявить переменную всей программы изнутри функции
конец
настрой()
пиши счёт, П, а, б, x, y, с[0], т.поле, режим
```
Вывод:
```
ещё не считали
считаю
10
10
0 3,14 2 1 3 4 a b тихий
```

- `ленивая` (также `лениво`, `ленивый`) — значение вычисляется, только когда переменная понадобилась впервые.
- `глобальная` — переменная видна во всей программе после того места, где она объявлена; её можно читать и менять из других функций.
- В `пусть а, б = …` число имён должно совпасть с числом значений, иначе ошибка «слева имён: 2, а справа значений: 3».

## 4. Выражения и приоритет операций (от слабого к сильному)

| Уровень | Операции |
|---|---|
| 1 | конвейер `затем`, `\|>` |
| 2 | `или` |
| 3 | `и` |
| 4 | `не` |
| 5 | `== != < > <= >=`, `в`, `не в` |
| 6 | `+ -` |
| 7 | `* / %` |
| 8 | унарный `-` |
| 9 | `^` (степень, правоассоциативная) |
| 10 | вызов `f(x)`, индекс `a[i]`, поле `a.b`, безопасные `?.` и `?.[ ]` |

- `+` складывает числа, склеивает строки (если хотя бы одна сторона строка) и списки.
- `строка * число` повторяет строку: `"ха" * 3` → `"хахаха"`.
- `список * число` повторяет список: `[1, 2] * 3` → `[1, 2, 1, 2, 1, 2]`.
- Слово `в` служебное (`x в список`), его нельзя взять именем переменной, поля или функции. Для высоты пишите `высота` или `выс`, не `в`.
- `%` — остаток, всегда неотрицательный для положительного делителя.
- `x в коллекция` — есть ли элемент в списке, подстрока в строке, ключ в словаре.
- `если условие то а иначе б` — условное выражение.
- Также понимаются символы `≠ ≤ ≥ × ÷`.

### Шаблоны строк
Внутри любой строки `{выражение}` заменяется значением. Чтобы написать саму фигурную скобку — `\{` и `\}`. Ещё экранирование: `\n` (перевод строки), `\t`, `\r`, `\\`, любая кавычка после `\` (`\"`, `\'`, `\«`, `\»`, `\“` …) и `\u{КОД}` — любой символ Юникода по шестнадцатеричному коду (`\u{263A}` → ☺).

```
пусть имя = "Аня"
пусть возраст = 12
пиши "Привет, {имя}! Через год тебе {возраст + 1}."
пиши "скобки: \{так\}"
```
Вывод:
```
Привет, Аня! Через год тебе 13.
скобки: {так}
```


### Кавычки в строках
Строку можно открыть любой обычной кавычкой; закрыть её нужно парной. Кавычки другого рисунка внутри строки — обычные символы. Вставки `{выражение}` работают во всех видах.

Пары:

- Машинные (как на клавиатуре), закрываются тем же знаком: `"…"`, `'…'`, `` `…` ``.
- Русские и французские ёлочки: `«…»`, одинарные `‹…›`. Вложение того же рисунка допускается и входит в значение строки: `«внешняя «внутренняя» ещё»`. Это правило сохранено для совместимости и на случай, когда набор «лапок» недоступен.
- Русские и немецкие лапки (Грамота.ру, Розенталь, ГОСТ Р 7.0.110-2025): открывает `„`, закрывает `“` (норма) или `”` (частый польский и «смешанный» вариант). Типографски правильно так: `«книга „Война и мир“»`.
- Как вставляет Word и телефон (английские типографские): `“…”` и `‘…’`. Нижние одинарные: `‚…‘` или `‚…’`.
- Если открывающая и закрывающая совпадают, как в финской и шведской традиции: `”…”` и `’…’` — такая кавычка в начале строки понимается как симметричная и закрывается тем же знаком.

Правила, чтобы язык не ломался:

1. Открывающая кавычка всегда закрывается только своей парой. `«привет"` — ошибка: строка открыта `«`, ожидается `»`.
2. Символ `“` (U+201C) неоднозначен в Юникоде: в английском это открывающая, в немецких и русских лапках — закрывающая. Решение зависит от места: в начале строки это английская открывающая (`“…”`); после `„` это закрывающая лапка.
3. Кавычки `»` и `›` в начале строки не открывают строку (ни «немецкие» `»…«`, ни финские `»…»`): в русском тексте это почти всегда лишняя закрывающая. Сообщение об ошибке подсказывает, чем открыть строку.
4. Одинаковые машинные и симметричные кавычки не вкладываются сами в себя: `"a "b" c"` — это две строки, как в Python и JavaScript. Чтобы вставить такую же кавычку, пишите `\"`, `\'` или возьмите другой рисунок: `"он сказал «да»"`.
5. Типографский апостроф `’` совпадает с закрывающей одинарной кавычкой. В `'it's'` или `‘it’s’` строка оборвётся на апострофе. Для текста с апострофами берите `"…"`, `«…»` или `“…”`, либо экранируйте: `'it\'s'`.
6. Обратные кавычки `` `…` `` — обычные строки «Понятного». Вставки пишутся как `{имя}`, а не как `${имя}` в JavaScript.
7. Автоисправление опечаток (раздел 14а) служебные кавычки не подменяет и в строки не заглядывает.
8. Комментарии (`#`, `//`) до конца строки кавычек не разбирают.

Редкие знаки вроде `‟` и `‛` не поддерживаются: компилятор назовёт их непонятным символом.

Полный пример (все эти строки — правильная программа):

```
пусть имя = «Аня»
пиши "машинные"
пиши 'одинарные'
пиши `обратные {1 + 1}`
пиши «ёлочки»
пиши ‹узкие›
пиши „лапки“
пиши „лапки-польские”
пиши “из Word, {имя}”
пиши ‘узкие из Word’
пиши «книга „Война и мир“»
пиши «внешняя «внутренняя» ещё»
пиши "он сказал «да»"
пиши «Ёлки {1 + 1}»
# «эта незакрытая кавычка в комментарии не мешает
пиши 'it\'s ok'
```
Вывод:
```
машинные
одинарные
обратные 2
ёлочки
узкие
лапки
лапки-польские
из Word, Аня
узкие из Word
книга „Война и мир“
внешняя «внутренняя» ещё
он сказал «да»
Ёлки 2
it's ok
```

Неправильно (так писать нельзя): `«привет"` — разные кавычки; `"a "b" c"` — это две строки, а не вложение; `'it's'` — апостроф оборвёт строку.


### Конвейер
`x затем f` — то же, что `f(x)`; `x затем f(a)` — то же, что `f(x, a)`.
Если `f` — не функция, а функция значения (метод), вызывается `x.f()`:
```
пусть текст = "  ПрИвЕт  "
пиши текст затем обрезать затем маленькими
пиши [3, 1, 2] |> отсортировано |> соедини("-")
```
Вывод:
```
привет
1-2-3
```


### Безопасный доступ `?.`
`покупатель?.заказ` даёт `ничего`, если `покупатель` — `ничего` (или нет такого поля); дальше цепочка тоже безопасна: `к?.заказ?.номер`.
`покупатель?.заказ = 5` записывает, только если `покупатель` — не `ничего`.
`список?.[0]`, `объект?.метод()` работают так же.

```
пусть покупатель = ничего
пиши покупатель?.заказ
пусть к = {заказ: {номер: 7}}
пиши к?.заказ?.номер
к?.адрес = "дом"
пиши к.адрес
```
Вывод:
```
ничего
7
дом
```


## 5. Ввод и вывод

Основная команда вывода — `пиши` (старое `напиши` тоже работает).

```
пусть a = 2
пусть b = 3
пиши "Сумма:", a + b      # значения через пробел
пусть имя = спроси("Как тебя зовут?")
пусть n = число(спроси("Сколько?"))
пиши "Привет, {имя}! Число: {n}"
```
Если на вопросы ответить `Аня` и `5`, вывод:
```
Сумма: 5
Привет, Аня! Число: 5
```


## 6. Условия

```
пусть x = 7
если x > 10 то
    пиши "много"
иначе если x > 5 то
    пиши "средне"
иначе
    пиши "мало"
конец
```
Вывод: `средне`. Слово `то` можно не писать в конце строки.


## 7. Циклы

```
пусть н = 0
пока н < 3
    н += 1
    пиши "пока", н
конец

повтори 3 раз
    пиши "раз"
конец

для каждого элемент из ["а", "б"]
    пиши элемент
конец

для каждого ключ, значение из {имя: "Оля", балл: 5}
    пиши ключ, значение
конец

для i от 3 до 1
    пиши i
конец

для i от 0 до 10 шаг 5
    пиши "шаг", i
конец
```
Вывод:
```
пока 1
пока 2
пока 3
раз
раз
раз
а
б
имя Оля
балл 5
3
2
1
шаг 0
шаг 5
шаг 10
```

Цикл с проверкой в конце (тело выполняется хотя бы один раз). Переменную для условия объявляйте **до** `делай`: имя, заведённое внутри тела, снаружи не видно, и `конец пока ответ != …` тогда не скомпилируется.

```
пусть ответ = ""
делай
    ответ = "секрет"
конец пока ответ != "секрет"
пиши "вошли"
```
Вывод: `вошли`.

`стоп` — выйти из цикла, `дальше` — перейти к следующему кругу. Вне цикла это ошибка компиляции.

Формы слов в циклах: `повтори 3 раза`, `для каждой буквы из …`, `для каждого x в список`, `для i с 1 по 10 шагом 2`.


## 8. Выбор

```
пусть n = 7
пусть премия = истина
выбор n
    вариант 0
        пиши "ноль"
    вариант 1, 2, 3                  # несколько значений
        пиши "мало"
    вариант 7 если премия то         # вариант с дополнительным условием
        пиши "счастливое"
    когда x если x > 100 то          # x — это n, и условие на него
        пиши "очень много"
    иначе
        пиши "что-то другое"
конец
```
Вывод: `счастливое`. Выполняется первый подходящий вариант, «проваливания» в следующий нет.


## 9. Функции

```
функция привет(имя, знак = "!")          # значение по умолчанию
    верни "Привет, " + имя + знак
конец

функция факториал(н)                      # рекурсия
    если н <= 1 то
        верни 1
    конец
    верни н * факториал(н - 1)
конец

пиши привет("Аня")
пиши факториал(10)
```
Вывод:
```
Привет, Аня!
3628800
```
- Функции, объявленные в блоке, видны во всём блоке (можно вызывать до объявления).
- Количество значений при вызове проверяется при компиляции.
- Без `верни` функция возвращает `ничего`.

### Безымянные функции (лямбды)
```
пусть удвоить = функция(x) => x * 2
пусть квадрат = x => x * x
пусть сложная = функция(a, b = 1)
    верни a * b
конец
пиши удвоить(5), квадрат(4)

```

## 10. Классы и структуры

```
класс Животное
    пусть имя = "безымянное"           # поле со значением по умолчанию
    функция создать(имя)               # вызывается при создании
        это.имя = имя                  # «это» и «себя» — текущий объект
    конец
    функция голос()
        верни "..."
    конец
    функция строкой()                  # как печатать объект
        верни "{это.имя} говорит {себя.голос()}"
    конец
конец

класс Кот наследует Животное
    функция голос()
        верни "мяу, а не " + родитель.голос()
    конец
конец

пусть к = Кот("Барсик")        # или: новый Кот("Барсик")
пиши к

структура Точка(x, y = 0)       # короткий класс только с полями

т.y = 5
пиши к, т, т.x, т.y
```
Вывод: `Барсик говорит мяу, а не ... Точка(x: 3, y: 5) 3 5`.


### Интерфейсы, общие и скрытые члены, свойства, абстрактные функции (с версии 2.4)

```
интерфейс Фигура                     # список функций, которые обязан иметь класс
    функция площадь()
    функция имя() -> строка
конец

класс Фигура2Д
    абстрактная функция площадь()    # без тела: её пишет наследник
конец

класс Квадрат наследует Фигура2Д реализует Фигура
    общая пусть создано = 0          # поле класса, а не объекта (static)
    скрытая пусть сторона = 0        # снаружи класса недоступно (проверяется при компиляции)
    функция создать(с)
        это.сторона = с
        Квадрат.создано += 1
    конец
    функция площадь()
        верни это.сторона ^ 2
    конец
    функция имя()
        верни "квадрат"
    конец
    свойство периметр                # читается как поле: к.периметр
        верни 4 * это.сторона
    конец
    общая функция единичный()        # вызывается у класса: Квадрат.единичный()
        верни Квадрат(1)
    конец
конец

пусть к = Квадрат.единичный()
пиши к.площадь(), к.периметр, Квадрат.создано
пиши экземпляр(к, Фигура), экземпляр(к, Квадрат), экземпляр(5, "число")
```
- `реализует И1, И2` — после объявления класса проверяется, что у него есть все функции интерфейсов, иначе ошибка «класс «К» обещал «реализует И», но в нём нет функции «ф»».
- `общая` (также `общий`, `статическая`) — член класса; обращение `Класс.имя`. Внутри общей функции `это` — сам класс.
- `скрытая` (также `скрытый`, `приватная`) — к полю или функции можно обращаться только через `это` или внутри функций этого класса и его наследников.
- `абстрактная функция` без тела: вызов у объекта, где она не написана, даёт понятную ошибку.
- `свойство имя` — вычисляемое поле только для чтения.
- `экземпляр(x, К)` — истина, если `x` — объект класса `К` (или наследника), подходит под интерфейс `К` или имеет тип с названием `"число"`, `"целое"`, `"строка"` и т. д.

### Перечисления

перечисление Цвет

    СИНИЙ = 10

### Ошибки разных типов (с версии 2.4)

Есть встроенный класс `Ошибка` с полем `сообщение`; от него можно наследовать свои ошибки. Блоков `если ошибка Тип как имя` может быть несколько — выполняется первый подходящий:
```
класс ОшибкаВвода наследует Ошибка
конец

попробуй
    брось ОшибкаВвода("нужно число")
если ошибка ОшибкаВвода как е
    пиши "Ввод:", е.сообщение
если ошибка строка как т          # брось "текст"
    пиши "Текст:", т
если ошибка как е                 # всё остальное (так же: если ошибка Ошибка как е)
    пиши "Другое:", е
наконец
    пиши "готово"
конец
```
- Тип — класс, интерфейс или название типа (`строка`, `число` …). `Ошибка` ловит всё, в том числе встроенные ошибки («делить на ноль нельзя» и т. п. приходят строкой).
- Если ни один блок не подошёл, ошибка летит дальше.
- Общий блок без типа после блоков с типом пишется с `как`: `если ошибка как е`.

### Проверки и выход
```
пусть возраст = 10
пусть список = [1, 2]
убедись возраст >= 0, "возраст не может быть отрицательным"   # иначе — ошибка с этим текстом
проверь(список.длина > 0)                                      # то же функцией
пиши "проверки прошли"
```
Вывод: `проверки прошли`.

`выход()` заканчивает программу сразу (`выход(3)` — с кодом 3); `попробуй` его не ловит. Пишите его последней командой, когда работа уже сделана.

## 14. Сообщения об ошибках

Ошибки пишутся по-русски с номером строки и столбца, при опечатках — с подсказкой:
```
Строка 2, столбец 1: непонятная команда «коннец». Возможно, вы имели в виду «конец»?
Строка 5, столбец 8: не знаю, что такое «счет». Возможно, вы имели в виду «счёт»?
Строка 1, столбец 7: в имени «сoк» смешаны русские и латинские буквы («сoк»). … Возможно, вы имели в виду «сок»?
Строка 1, столбец 14: сравнения нельзя писать цепочкой: «a < b < c» понимается неоднозначно. Напиши через «и»: a < b и b < c
Строка 3, столбец 1: нельзя изменить «дни»: она объявлена как «пусть навсегда»
Строка 7: в списке нет элемента с номером 5 (элементов: 3, нумерация с 0)
```
При компиляции проверяются: необъявленные имена, повторные объявления, изменение констант, `стоп`/`дальше` вне цикла, `верни` вне функции, `это` вне класса, количество значений при вызове функций, неизвестные типы и явное несовпадение типа.

## 14а. Опечатки, которые язык прощает

Компилятор сам исправляет опечатку в служебном слове и пишет предупреждение, но только там, где это не может изменить смысл правильной программы:

1. **Слово в начале команды**, за которым сразу идёт имя, число или строка (а не `=`, `(`, `.` и т. п.): `пуст x = 1`, `напишы x`, `ЕСЛИ x > 1 то`. Правильная программа так начинаться не может, поэтому двусмысленности нет. Если переменная называется `пуст` и стоит `пуст = 2`, это присваивание, и ничего не исправляется.
2. **Слово-окончание блока** одно на строке: `конц`, `инче` → `конец`, `иначе`.
3. **Ожидаемое слово** на своём месте: `повторить 3 рза` → `раз`, `для i от 1 дo 5` → `до`, `тo` → `то`.
4. **Латинские буквы-двойники** в служебном слове: `пoка` с латинской `o` → `пока`.

Исправление делается, только если опечатка — одна правка (лишняя, пропущенная, заменённая буква или две переставленные соседние) и подходящее слово ровно одно. Слова короче 3 букв не исправляются. Если вариантов несколько или опечатка больше, компиляция останавливается с подсказкой «Возможно, вы имели в виду …». Опечатки в именах переменных и функций **никогда** не исправляются автоматически — только подсказываются, потому что это могли быть разные имена.

Предупреждения выглядят так:
```
Предупреждение. Файл «prog.pon», строка 1, столбец 1: опечатка «пуст» исправлена на «пусть»
```

## 14б. Ограничения (защита от зависаний)

- Вложенность выражений и блоков — не больше 200 уровней.
- Строка — не длиннее 100 миллионов символов (`"a" * 10^12` даёт понятную ошибку, а не падение).
- В песочнице и в `запустить` из тестов программа останавливается после 5 миллионов шагов цикла, в песочнице ещё и через 20 секунд. В собранных программах ограничения шагов нет.
- Слишком глубокая рекурсия даёт ошибку «слишком глубокая рекурсия».

## 14в. Имена на кириллице в JavaScript и других языках

- В JavaScript каждое имя получает префикс `$` (`счёт` → `$счёт`), так что оно не совпадёт ни со служебным словом JavaScript, ни с внутренними именами компилятора.
- `ponyatny компилировать файл.pon --ascii` записывает имена только латиницей: каждый не-ASCII символ заменяется на `$` и 6 шестнадцатеричных цифр (`ж` → `$$000436`). Такая запись взаимно однозначна — два разных имени никогда не совпадут.
- `ponyatny перевести файл.pon --в python --латиница` (также javascript, csharp) переводит русские имена транслитерацией: `счёт` → `schyot`, `Щука` → `Shchuka`. Если получилось имя, которое уже занято (другим именем, служебным словом языка или функцией из подготовительного кода переводчика), добавляется `_`, `_2`, `_3` …: `привет` → `privet`, а `privet` → `privet_`. Без `--латиница` русские имена остаются русскими (Python, JavaScript и C# их поддерживают), а совпадения со служебными словами всё равно разводятся через `_`.
- При переводе с Python или JavaScript в «Понятный» имена, которых нет в языке, переводятся безопасно: `$x` → `u24_x`, `π` → `u3c0_`, смешанное `getИмя` → `get_Имя`, служебные слова «Понятного» получают `_`. Имена Python приводятся к NFKC, как это делает сам Python (`ﬁle` и `file` — одно имя).

## 17. Синонимы, формы слов и шуточный диалект (с версии 2.4)

Язык понимает слова в разных формах — повелительной и неопределённой, разного рода и падежа; буквы `ё` и `е` в этих словах не различаются, регистр не важен. Компилятор всегда приводит их к основным коротким словам языка (`пиши`, `брось`, …), а переводчики и декомпилятор ИванКода пишут только эти обычные (нешуточные) слова.

**Где действуют.** Синоним в начале команды понимается, только если дальше не идёт `=`, `+=`, `(`, `.`, `[` и т. п. Поэтому `пусть паника = 1`, `паника = 2`, `выведи(3)` (если `выведи` — ваша функция) работают как раньше. Фразы из нескольких слов (`ну всё`, `кричи на систему`) в правильной программе раньше встретиться не могли, поэтому они понимаются всегда в начале строки; запятые между их словами можно ставить.

## 19. Что нового в версии 2.5

Основная форма в примерах — `пиши` (`напиши` — синоним). Новые слова понимаются в нескольких формах.

### Метки и переход

Метку можно ставить только в теле функции или программы, не внутри `если` / `пока`. Переход (`иди к`) можно писать и внутри условия. Имя метки не должно быть служебным словом (не называйте метку `конец`).

```
пусть i = 0
метка старт
i += 1
если i < 3 то
    иди к старт
конец
пиши i
```

Синонимы: `ярлык`, `перейди к`, `перейти к`, `прыгни к`, `беги к`, `телепортируйся к`, `goto`.

### Ссылки и размер

`ссылка x`, `указатель на x` и `&x` создают безопасную обёртку (не настоящий указатель Си: арифметики указателей нет). Разыменование — `*п` или `п.значение`. `размер(x)` / `sizeof(x)` — абстрактный размер: число 8, логическое 1, строка — длина×2, список — число элементов, словарь и множество — размер, ссылка 8, объект — число полей.

```
пусть x = 10
пусть п = ссылка x
*п = 20
пиши x, размер(x)
```

### Свойства: получить и установить

Слово `в` служебное, поэтому высоту нельзя назвать `в`.

```
класс Прямоугольник
    пусть ширина = 0
    пусть высота = 0
    функция создать(ширина, высота)
        это.ширина = ширина
        это.высота = высота
    конец
    свойство периметр
        получить
            верни 2 * (это.ширина + это.высота)
        конец
        установить значение
            пусть сторона = значение / 4
            это.ширина = сторона
            это.высота = сторона
        конец
    конец
конец
пусть п = Прямоугольник(2, 3)
пиши п.периметр
п.периметр = 20
пиши п.ширина, п.высота, п.периметр
```
Вывод:
```
10
5 5 20
```


Синонимы: `получи`, `взять`, `геттер` / `установи`, `поставить`, `поставь`, `сеттер`. Старая форма «только геттер» (`свойство имя` + тело + `конец`) по-прежнему работает.

### Цепочка конструкторов

Несколько функций `создать` с разным числом значений. `это(...)` вызывает другой конструктор этого же класса, `родитель(...)` — конструктор родителя.

```
класс Точка
    пусть x = 0
    пусть y = 0
    функция создать(x)
        это.x = x
        это.y = 0
    конец
    функция создать(x, y)
        это(x)
        это.y = y
    конец
конец
пусть а = Точка(5)
пусть б = Точка(1, 2)
пиши а.x, а.y, б.x, б.y
```
Вывод: `5 0 1 2`.

### Потоки и асинхронность

`асинхронная функция` / `асинхронный` / `асинхронно` возвращает задачу. `ждать`, `ожидай`, `жди` получают её результат. `поток` / `нить` / `параллельно` / `в фоне` запускает тело сразу (это совместная задача в том же потоке, а не отдельная нить операционной системы; настоящий `Promise` извне так дождаться нельзя).

конец

Строки принимают любые обычные кавычки, в том числе типографские из Word и с телефона. Правила и полный собирающийся пример — в разделе 4, «Кавычки в строках». Кратко:

## 21. Что нового в версии 2.7

### Ввод, который закончился

`спроси()` возвращает `ничего`, только если ввода больше нет. Тогда программа печатает в поток ошибок «Ввод закончился — программа завершена.» и выходит с кодом 0. Так бывает при Ctrl+D или конце файла в консоли и при «Отмене» в окне ввода песочницы, «Строки» и iOS. Поэтому цикл `пока истина … спроси(…)` больше не зависает.

### Перенос длинных строк

Перенос допускается:

- строка, оканчивающаяся на `\`, продолжается следующей;
- без `\` — если следующая строка начинается с `.`, `?.`, `|>`, `+`, `/`, `%`, `^`, `==`, `!=`, `<`, `>`, `<=`, `>=`, `::`, `=>` или со слов `и`, `или`, `то`;
- внутри скобок `( [ {`, как и раньше.

Минус в начале строки переноса не означает: это отдельное выражение `-x`. Ставьте `\` или переносите после знака.

```
пусть итого = сумма(цены) \
    + 100
пусть имя = "  ВАСЯ  "
    .обрезать()
    .маленькими()
если итого > 100
    и длина(цены) == 4 то
    пиши "ок"
конец
```

### Первая буква в любом регистре

Встроенные функции, классы и константы находятся и с маленькой, и с большой первой буквы: `ошибка("…")` = `Ошибка("…")`, `пи` = `ПИ`, `если ошибка ошибка как е`, `Пиши_ошибку` и т. п. Служебные слова и так не различают регистр. Ваши собственные переменные различают его по-прежнему: `имя` и `Имя` — разные имена. Если вы объявили своё `окно`, оно закрывает встроенное.

### Квантовые вычисления: `стд/квант`

Настоящий симулятор вектора состояний (до 16 кубитов, 2¹⁶ комплексных амплитуд). Кубит 0 — младший бит, как в Qiskit. Измерение схлопывает состояние по правилу Борна. Случайность замеров берётся из генератора Парка — Миллера с зерном (`КвантовыйРегистр(н, зерно)`, по умолчанию 2026), поэтому один и тот же запуск всегда даёт один и тот же результат.

```
подключи "стд/квант"
пусть р = КвантовыйРегистр(2)
р.адамар(0)
р.cnot(0, 1)
пиши р.состояние()        # 0,7071|00⟩ + 0,7071|11⟩
пиши р.вероятности()
пиши р.замеры(1000)
пиши округли(гровер(4, 11).вероятности()["|1011⟩"], 4)   # 0,9613
```

Методы регистра: `вентиль` (любая матрица 2×2, с управляющими кубитами), `адамар`, `паули_x/y/z`, `фаза`, `фаза_s`, `фаза_t`, `поворот_x/y/z`, `cnot` / `управляемое_не`, `cz`, `управляемая_фаза`, `тоффоли`, `обмен`, `кет`, `вероятности`, `вероятность_единицы`, `измерь`, `измерь_все`, `замеры`, `амплитуда`, `состояние`, `строкой`. ### Шуточные операторы (без случайности)

Все шуточные операторы детерминированы: один и тот же код всегда делает одно и то же.

| Конструкция | Что делает |
|---|---|
| `авось_сработает … конец` | выполняет блок всегда. Если внутри ошибка, она проглатывается и печатается «Штатный режим, расходимся»; внутри функции функция тут же возвращает 42. Выход из программы и защита от зависаний не проглатываются |
| `приложить_подорожник(x)` | если вычисление `x` упало или дало `ничего`, возвращает «Да вроде работает», иначе само значение |
| `сделать_вид_что_так_и_задумано … конец` | ошибка внутри показывается зелёным как «… — Фича активирована», программа идёт дальше. Без блока (отдельной строкой) включает этот режим до конца программы |
| `интеграл x от a до b [шагов N \| шаг h] [как имя] … конец` | честный численный интеграл по методу Симпсона (по умолчанию 1000 шагов). Последнее выражение блока — подынтегральная функция, результат — в переменной `площадь` или в `имя` |
| `чтоб_никто_не_догадался … конец` | блок выполняется, но всё, что он печатает, скрывается |
| `ы` | ничего не делает |
| `памятник ИМЯ = …` | то же, что `константа` («Кто ж его посадит? Он же памятник!») |
| `птичку_жалко` | то же, что `стоп` |

Приколы из советских фильмов:

| Функция | Фильм | Что делает |
|---|---|---|
| `электроник(ф, …аргументы)` | «Приключения Электроника» | вызывает `ф`, печатает «Электроник сделал всё за Сыроежкина» и возвращает результат |
