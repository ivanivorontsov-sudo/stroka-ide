# Строка

Удобный редактор кода для Android-смартфона: подсветка языков, панель символов над клавиатурой, свайп-курсор, голосовое программирование, запуск Python, JavaScript и языка «Понятный», просмотр HTML/Markdown, Git (JGit), шаблоны проектов и автосохранение.

Версия **1.8.0**: сборка готового **APK** и **Windows EXE** из одного файла, в том числе программы на «Понятном». Новый код этой версии написан с помощью ИИ.

## Сборка на устройстве

Для «Понятного» используется полный конвейер, а не только подстановка в готовый шаблон:

1. Компилятор «Понятный» переводит программу в JavaScript.
2. **APK:** создаётся настоящий Android-проект (манифест, ресурсы, Java-оболочка с WebView), затем `aapt2` → компилятор Java → `d8` → `zipalign` → подпись `apksig` (v2/v3).
3. **EXE:** тот же JavaScript встраивается в программу на C с движком QuickJS и собирается кросс-компилятором MinGW в 64-битный PE для Windows.

Готовый файл сохраняется в папку, которую вы выбираете (доступ через системный выбор папки; выбор запоминается).

Кнопка «Собрать APK» / «Собрать EXE» — в меню. Шаблон **«Понятный: калькулятор»** создаёт рабочий калькулятор.

Целевой телефон разработки: **realme 15 5G** (MediaTek Dimensity 7300+, **arm64-v8a**, 8 или 12 ГБ ОЗУ, realme UI 6 на Android 15, возможны обновления до Android 16). На Android 10+ нельзя запускать исполняемые файлы из обычной папки данных приложения (W^X); нативные инструменты нужно класть как библиотеки в каталог `.so` приложения. Размер APK Строки не ограничивался.

**iPhone:** собрать и установить APK на iPhone нельзя — это ограничение Apple, а не Строки. «Для любых смартфонов» в смысле Android (arm64 и типичные x86_64-эмуляторы). Старые 32-битные телефоны в этой версии не являются основной целью.

## Запуск «Понятного»

Файлы `.pon` подсвечиваются, запускаются кнопкой «Старт» (компилятор встроен) и могут собираться в APK/EXE. Справка по синтаксису — в меню.

## Что взято из других проектов Ивана

- **Пингвин** (https://github.com/ivanivorontsov-sudo/pingvin): идея и проверенный приём «собрать APK на телефоне» — шаблон + правка пакета + подпись библиотекой `apksig`. В этой версии основной путь для «Понятного» — полный `aapt2`/`d8`, а не только перепаковка ярлыка Пингвина. Полный Debian/PRoot/Wine из Пингвина в Строку не встраивался: он тяжелее и медленнее, чем прямой конвейер сборки.
- **ИванКод**: формат быстрого EXE-контейнера и шаблон WebView-APK оставлены как запасной быстрый путь; для «Понятного» по просьбе Ивана сделан полный конвейер. Подход к ИИ (один чат, правка проекта, повторная сборка при ошибках) заложен в настройки; окно чата ещё доделывается.

Компилятор «Понятный» встроен из репозитория ponyatny.
