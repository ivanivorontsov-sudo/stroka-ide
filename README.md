# Строка

Удобный редактор кода для Android-смартфона: подсветка 13 языков, панель символов над клавиатурой, свайп-курсор, голосовой ввод кода и команд, запуск Python и JavaScript, просмотр HTML/Markdown, Git (JGit), шаблоны проектов и автосохранение.

## Голосовой ввод

- **Авто:** при подключённой сети используется системный распознаватель Android (часто Google Speech Services, если он выбран на устройстве); без сети приложение пробует Android on-device (Android 12+), затем Vosk.
- **Android на устройстве:** отдельный офлайн-режим через `SpeechRecognizer.createOnDeviceSpeechRecognizer`. Требуются Android 12+ и поддержка выбранного языка системной службой.
- **Vosk:** полностью локальное распознавание после загрузки русской или английской модели через Настройки → Голосовой ввод.
- Системному распознавателю передаются подсказки со словами команд и символов (Android 13+); приложение запрашивает до пяти вариантов распознанной фразы и выбирает вариант, похожий на известную команду.
- Команды понимают распространённые варианты произношения и небольшие ошибки распознавания. Нераспознанные фразы остаются обычной диктовкой кода.

**Конфиденциальность:** стандартный системный распознаватель может отправлять аудио на сервер провайдера — это зависит от службы устройства. Для обработки на телефоне выбирайте «Android на устройстве» (если доступен) или «Vosk».
