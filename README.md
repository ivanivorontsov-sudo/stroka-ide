# Строка

**Строка** — мобильная среда разработки для Android: редактор исходного кода, запуск Python и JavaScript, встроенный компилятор языка «Понятный», голосовой ввод, Git/GitHub, чат с ИИ и сборка отдельных программ прямо на телефоне.

- **Текущая версия исходников:** 1.8.2
- **Android:** 8.0 и новее (minSdk 26)
- **Архитектуры:** arm64-v8a и x86_64; опубликованная release-сборка APK собирается для arm64-v8a
- **Лицензия проекта:** MIT

## Возможности редактора

- Подсветка синтаксиса для Python, JavaScript/TypeScript, HTML/XML/SVG, CSS/SCSS/Less, Kotlin, Java, C/C++, JSON, Markdown, GDScript, ассемблера 6502 и языка «Понятный».
- Несколько открытых файлов во вкладках, дерево файлов и папок, создание файлов и проектов из шаблонов.
- Работа как с файлами в памяти приложения, так и с папками телефона, которые пользователь подключает через системный выбор папки Android (Storage Access Framework).
- Автосохранение, восстановление открытой сессии, отмена и повтор действий, номера строк, перенос длинных строк, настраиваемые размер шрифта и отступы.
- Автодополнение, парные скобки и кавычки, автоматические отступы и настраиваемая панель дополнительных клавиш над экранной клавиатурой.
- Поиск и замена: регулярные выражения, учёт регистра, поиск целых слов, переход к следующему и предыдущему совпадению.
- Переключение светлой/тёмной темы, настройка виброотклика и запрос повышенной частоты обновления экрана на совместимых устройствах.

## Запуск и просмотр

| Тип | Что умеет Строка |
|---|---|
| Python (.py, .pyw) | Запуск на Python 3.12 через Chaquopy; поддерживаются программы с консольным вводом/выводом и отдельный Android-интерфейс для сценариев, использующих Android API |
| JavaScript (.js, .mjs, .cjs) | Запуск во встроенной WebView-среде с выводом console.log, предупреждений и ошибок в консоль Строки |
| «Понятный» (.pon) | Компиляция встроенным компилятором в JavaScript и запуск во встроенной среде выполнения |
| HTML, CSS | Просмотр веб-содержимого во встроенной WebView |
| Markdown | Просмотр документа в HTML-представлении |
| Остальные языки | Универсальный предпросмотр исходного кода; это не подмена реального запуска или эмуляции целевой платформы |

Редактор также открывает и подсвечивает другие перечисленные выше языки. Наличие подсветки не означает, что язык можно запустить или собрать на телефоне.

## Голосовое программирование

Голосовой ввод поддерживает русский и английский языки.

Доступные варианты распознавания:
- системный сервис распознавания речи Android (обычно Google);
- встроенное офлайн-распознавание Android, если оно поддерживается устройством и на нём установлена языковая модель;
- офлайн-модели Vosk: небольшая русская и английская модели, которые можно скачать в настройках.

В автоматическом режиме Строка выбирает доступный движок и при некоторых ошибках сетевого распознавания пробует перейти на офлайн-вариант. В настройках можно выбрать движок и язык. Режимы голосового ввода: обычная диктовка, голосовые блоки кода или расширенные конструкции. Дополнительно доступны команды редактирования и шаблоны для часто используемых конструкций.

Для скачивания моделей Vosk нужен интернет; после установки соответствующая модель работает локально.

## Чат с ИИ

Встроенный чат получает текущий открытый файл и ограниченный текстовый снимок локального проекта (до 80 файлов / 90 000 символов; бинарные файлы и каталоги сборки исключаются). Он может анализировать связи между файлами. Кнопка «Применить» пока применяет один основной блок кода к открытому файлу; массовое применение нескольких файлов с подтверждением diff — отдельный следующий этап.

Подключение настраивается в параметрах:
- адрес API, совместимый с форматом OpenAI Chat Completions;
- название модели;
- ключ API.

По умолчанию используется адрес DeepSeek API и модель `deepseek-chat`, но пользователь может указать другой совместимый сервис. Ключ хранится в защищённом хранилище Android и не добавляется в исходный код или историю Git. При обращении к ИИ текст запроса и контекст файла передаются выбранному пользователем API-провайдеру.

## Git и GitHub

Встроенный Git-клиент на базе JGit позволяет:
- клонировать репозитории;
- инициализировать Git в папке проекта;
- смотреть статус изменений;
- получать изменения через pull;
- создавать коммиты;
- отправлять изменения через push.

Логин, имя и e-mail автора коммитов задаются в настройках. Для операций с GitHub можно указать Personal Access Token; приложение хранит токен в защищённом хранилище Android. Права токена должны соответствовать операциям и репозиториям, с которыми работает пользователь.

## Сборка программ на телефоне

Строка содержит локальный конвейер сборки. Пользователь выбирает папку назначения через системный диалог Android; выбранная папка запоминается.

### APK

В меню доступны команды сборки APK. Поддерживаются следующие входные файлы:

- **.pon** — компилятор «Понятный» переводит исходник в JavaScript; затем создаётся Android-проект с WebView-оболочкой и ресурсами.
- **.js** — JavaScript-программа упаковывается в WebView-приложение.
- **.html / .htm** — HTML-файл становится содержимым WebView-приложения.
- **.py / .pyw** — используется отдельный сборщик Python-приложения на базе Chaquopy.
- **.java** — собирается однофайловое Android-приложение, если исходник содержит Activity, наследующий `android.app.Activity`.
- **.kt** — Kotlin/JVM компилируется Android-патченным Kotlin compiler; первая поддерживаемая форма — один Kotlin-файл с классом `Activity`. Kotlin runtime включается в итоговый DEX.

Файл `.kts` не является самостоятельной программой Android: это Kotlin Script, обычно исполняемый Gradle.

Для сборки используются aapt2, Eclipse ECJ для Java, Android-патч Kotlin/JVM compiler для Kotlin, D8, zipalign и apksig. Сборка Kotlin требует Android Activity и пока не является полноценной заменой Gradle-проекту с несколькими модулями и произвольными плагинами.

### Windows EXE

Из меню можно собрать Windows EXE из файлов **.pon** и **.js**. «Понятный» предварительно компилируется в JavaScript, а исполняемый файл содержит программу и QuickJS runtime. Это сборка для Windows x64, а не универсальный исполняемый файл для Android или Linux.

Сборка выполняется на самом телефоне и может занимать время. Для некоторых операций требуются ресурсы и нативные компоненты под архитектуру устройства. Если приложение сообщает, что инструменты сборки не найдены, проверьте целостность установки и архитектуру APK.

## «Понятный»

Компилятор языка «Понятный» встроен в Строку. Файлы `.pon` распознаются редактором, подсвечиваются, запускаются кнопкой «Старт» и могут собираться в APK или Windows EXE. Синтаксис и примеры доступны из меню приложения. Для компиляции используется ядро языка и его стандартная библиотека из проекта [ponyatny](https://github.com/ivanivorontsov-sudo/ponyatny).

## Установка и выпуск

Откройте раздел [Releases](https://github.com/ivanivorontsov-sudo/stroka-ide/releases) и скачайте актуальный APK.

GitHub Actions выполняет unit-тесты, собирает release APK для arm64-v8a и Android App Bundle, проверяет подпись и публикует файлы в выпуск `latest`. Отдельный workflow `Verify Android build` проверяет PR и собирает Debug APK. Workflow `Build Windows installer` доступен в Actions → Build Windows installer: он принимает GitHub Releases URL и SHA-256 portable EXE и собирает стандартный Setup.exe через Inno Setup.

## Ограничения

- Это приложение для Android; установка APK на iPhone не поддерживается.
- Подсветка синтаксиса доступна для большего числа языков, чем запуск и сборка. Kotlin пока ограничен однофайловым Android Activity; Kotlin Script, Kotlin/Native, Kotlin/JS, Kotlin/Wasm, Compose preview и полноценные multi-module Gradle проекты ещё не поддерживаются.
- Portable Windows EXE собирается только из JavaScript и «Понятного» и предназначен для Windows x64. Стандартный Setup.exe создаётся отдельным Windows GitHub Actions workflow.
- Для голосового ввода и чата с ИИ доступность зависит от выбранного движка, установленных моделей, сети и настроек провайдера.
- Перед распространением собранного приложения проверьте его работу на целевых устройствах и соблюдение лицензий зависимостей.
