# Строка

Удобный редактор кода для Android-смартфона: подсветка 13 языков, панель символов над клавиатурой, свайп-курсор, голосовой ввод кода (Google + офлайн Vosk), запуск Python и JavaScript, просмотр HTML/Markdown, Git (JGit), шаблоны проектов, автосохранение.

Сборка: GitHub Actions → релиз `latest`.
