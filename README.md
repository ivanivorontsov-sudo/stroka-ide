# Строка

**Строка** — мобильная среда разработки для Android: редактор исходного кода, запуск Python и JavaScript, встроенный компилятор языка «Понятный», голосовой ввод, Git/GitHub, чат с ИИ и сборка отдельных программ прямо на телефоне.

- **Текущая версия исходников:** 1.8.3 (`versionCode = 13`)
- **Статус выпуска:** изменения находятся в PR; до прохождения CI и публикации в GitHub Releases версия 1.8.3 не считается выпущенной. Текущий опубликованный APK может оставаться на предыдущей версии.
- **Android:** 8.0 и новее (minSdk 26)
- **Архитектуры:** arm64-v8a и x86_64; опубликованная release-сборка APK собирается для arm64-v8a
- **Лицензия проекта:** MIT

## Возможности редактора

- Подсветка синтаксиса для Python, JavaScript/TypeScript, HTML/XML/SVG, CSS/SCSS/Less, Kotlin, Java, C/C++, JSON, Markdown, GDScript, ассемблера 6502 и языка «Понятный».
- Несколько открытых файлов во вкладках, дерево файлов и папок, создание файлов и проектов из шаблонов.
- Работа как с файлами в памяти приложения, так и с папками телефона, которые пользователь подключает через системный выбор папки Android (Storage Access Framework).
- Автосохранение, восстановление открытой сессии, отмена и повтор действий, номера строк, перенос длинных строк, настраиваемые размер шрифта и отступы.
- Автодополнение, парные скобки и кавычки, автоматические отступы и настраиваемая панель дополнительных клавиш над экранной клавиатурой.
- Поиск и замена: регулярные выражения, учёт регистра, поиск целых слов, переход к следующему и предыдущему совпадению.
- Переключение светлой/тёмной темы, настройка виброотклика и запрос повышенной частоты обновления экрана на совместимых устройствах.

## Запуск и просмотр

| Тип | Что умеет Строка |
|---|---|
| Python (.py, .pyw) | Запуск на Python 3.12 через Chaquopy; поддерживаются программы с консольным вводом/выводом и отдельный Android-интерфейс для сценариев, использующих Android API |
| JavaScript (.js, .mjs, .cjs) | Запуск во встроенной WebView-среде с выводом console.log, предупреждений и ошибок в консоль Строки |
| «Понятный» (.pon) | Компиляция встроенным компилятором в JavaScript и запуск во встроенной среде выполнения |
| HTML, CSS | Просмотр веб-содержимого во встроенной WebView |
| Markdown | Просмотр документа в HTML-представлении |
| Остальные языки | Универсальный предпросмотр исходного кода; это не подмена реального запуска или эмуляции целевой платформы |

Редактор также открывает и подсвечивает другие перечисленные выше языки. Наличие подсветки не означает, что язык можно запустить или собрать на телефоне.

## Голосовое программирование

Голосовой ввод поддерживает русский и английский языки.

Доступные варианты распознавания:
- системный сервис распознавания речи Android (обычно Google);
- встроенное офлайн-распознавание Android, если оно поддерживается устройством и на нём установлена языковая модель;
- офлайн-модели Vosk: небольшая русская и английская модели, которые можно скачать в настройках.

В автоматическом режиме Строка выбирает доступный движок и при некоторых ошибках сетевого распознавания пробует перейти на офлайн-вариант. В настройках можно выбрать движок и язык. Режимы голосового ввода: обычная диктовка, голосовые блоки кода или расширенные конструкции. Дополнительно доступны команды редактирования и шаблоны для часто используемых конструкций.

Для скачивания моделей Vosk нужен интернет; после установки соответствующая модель работает локально.

## Чаты ИИ и работа с проектом

Встроенный чат работает в двух режимах:

- **API:** адрес, модель и ключ задаются в настройках. Используется OpenAI-совместимый Chat Completions API.
- **Веб-чаты:** можно войти в аккаунт прямо во встроенном WebView и отправлять задания из того же окна чата без отдельного API-ключа. Встроены ChatGPT, Claude, Gemini, Gemini Notebook, Grok, DeepSeek, Qwen, Kimi, MiniMax, Perplexity, Poe, Mistral Le Chat, Copilot, Алиса, You.com, Duck.ai, Pi, HuggingChat, OpenRouter и Manus. Cookies и авторизационная сессия остаются в хранилище Android WebView; пароль приложение отдельно не сохраняет.

История чатов сохраняется локально. Можно создать новый чат, переключиться на сохранённый чат или открыть список диалогов выбранного сайта в WebView и выбрать существующий диалог. Управление провайдером, создание и выбор диалогов, вход в веб-чат и настройки находятся в меню верхней панели, а не занимают постоянную полосу над перепиской. Для веб-чата сохраняется URL конкретного разговора. Поля ввода и кнопки отправки распознаются адаптивно по ARIA-ролям, доступным именам, label/placeholder, типу элемента и его положению на экране; CSS-классы конкретных сайтов используются только как дополнительные подсказки; обходятся также открытые Shadow DOM. Если локальная эвристика не справляется, включённый в настройках AI-помощник при наличии сохранённого OpenAI-совместимого API-ключа может выбрать поле по списку его технических метаданных (тип, подпись, placeholder и размеры). В этом резервном запросе не передаются переписка, текст страницы или введённые значения. Встроена диагностика найденных элементов и снимок структуры страницы при сбое. Это помогает переживать редизайн сайтов, но не гарантирует работу при CAPTCHA, блокировке WebView, закрытом DOM или изменении логики сайта; в таких случаях пользователь может открыть нужный диалог вручную.

Перед первым запросом Строка подгружает текстовый снимок проекта: до 500 текстовых файлов и 300 000 символов за один запрос. Это позволяет ИИ анализировать связанные исходники, а не только открытый файл. Бинарные файлы, зависимости, сборочные каталоги, скрытые настройки, ключи и файлы с именами вроде `secret`, `token`, `password`, `keystore` намеренно исключаются. Если проект больше лимита, чат сообщает, что часть файлов не вошла. Снимок проекта и текущий файл добавляются в первый запрос и остаются в контексте выбранного диалога.

ИИ должен возвращать структурированный JSON:
```json
{
  "summary": "Что изменено",
  "operations": [
    {
      "action": "write",
      "path": "src/Main.kt",
      "content": "полный текст файла"
    }
  ]
}
```
Поддерживаются операции `write` и `delete`. Изменения можно применять как набор структурированных патчей к нескольким файлам проекта. API использует JSON Schema Structured Outputs, если сервер модели это поддерживает, и запасной JSON mode для совместимых API. Веб-чаты получают ту же JSON-схему в инструкции.

Перед записью Строка проверяет JSON, относительные пути, попытки выхода за корень проекта, повторяющиеся пути и запретные файлы. Все изменения показываются списком; пользователь отдельно подтверждает применение. Перед заменой или удалением создаётся резервная копия во внутреннем хранилище приложения. Запуск команд из ответа ИИ автоматически не выполняется.

Ключ API хранится в защищённом хранилище Android и не добавляется в исходный код или историю Git.

## Git и GitHub

Встроенный Git-клиент на базе JGit позволяет:
- клонировать репозитории;
- инициализировать Git в папке проекта;
- смотреть статус изменений;
- получать изменения через pull;
- создавать коммиты;
- отправлять изменения через push.

Логин, имя и e-mail автора коммитов задаются в настройках. Для операций с GitHub можно указать Personal Access Token; приложение хранит токен в защищённом хранилище Android. Права токена должны соответствовать операциям и репозиториям, с которыми работает пользователь. В Настройки → GitHub Actions можно просматривать последние запуски, список активных workflow и отправлять workflow_dispatch для выбранной ветки. Для этого PAT нужны Actions: Read and write и Contents: Read.

## Сборка программ на телефоне

Строка содержит локальный конвейер сборки. Пользователь выбирает папку назначения через системный диалог Android; выбранная папка запоминается.

### APK

В меню доступны команды сборки APK. Поддерживаются следующие входные файлы:

- **.pon** — компилятор «Понятный» переводит исходник в JavaScript; затем создаётся Android-проект с WebView-оболочкой и ресурсами.
- **.js** — JavaScript-программа упаковывается в WebView-приложение.
- **.html / .htm** — HTML-файл становится содержимым WebView-приложения.
- **.py / .pyw** — используется отдельный сборщик Python-приложения на базе Chaquopy.
- **.java** — собирается однофайловое Android-приложение, если исходник содержит Activity, наследующий `android.app.Activity`. Используется Eclipse ECJ с уровнем языка Java 8: поддерживаются лямбды, ссылки на методы и стандартные конструкции Java 8; это не компилятор Java 17.
- **.kt** — Kotlin/JVM компилируется Android-патченным Kotlin compiler; первая поддерживаемая форма — один Kotlin-файл с классом `Activity`. Kotlin runtime включается в итоговый DEX.

Перед сборкой APK можно задать `versionName` и возрастающий `versionCode`, выбрать изображение PNG/JPEG/WebP из галереи или сгенерировать случайный emoji. В настройках доступны импорт и экспорт PKCS#12-ключа подписи; перед импортом приложение проверяет сертификат и сохраняет резервную копию прежнего ключа. Никогда не публикуйте P12-файл и его пароль. Замена ключа меняет подпись будущих APK, поэтому существующие приложения с прежней подписью нельзя будет обновить новым ключом. Фото автоматически вписывается в квадратную иконку с безопасным кадрированием и создаются ресурсы для основных плотностей экрана.

Файл `.kts` не является самостоятельной программой Android: это Kotlin Script, обычно исполняемый Gradle.

Для сборки используются aapt2, Eclipse ECJ 3.18.0 для Java (уровень языка Java 8), Android-патч Kotlin/JVM compiler 2.4.0 для Kotlin, D8, zipalign и apksig. Для Java 8 на Android в компиляторный bootclasspath добавляются `android.jar` и `core-lambda-stubs.jar`. Сборка Kotlin требует Android Activity и пока не является полноценной заменой Gradle-проекту с несколькими модулями и произвольными плагинами.

### Windows EXE

Из меню можно собрать Windows EXE из файлов **.pon** и **.js**. «Понятный» предварительно компилируется в JavaScript, а исполняемый файл содержит программу и QuickJS runtime. Это сборка для Windows x64, а не универсальный исполняемый файл для Android или Linux.

Сборка выполняется на самом телефоне и может занимать время. Для некоторых операций требуются ресурсы и нативные компоненты под архитектуру устройства. Если приложение сообщает, что инструменты сборки не найдены, проверьте целостность установки и архитектуру APK.

## «Понятный»

Компилятор языка «Понятный» встроен в Строку. Файлы `.pon` распознаются редактором, подсвечиваются, запускаются кнопкой «Старт» и могут собираться в APK или Windows EXE. Синтаксис и примеры доступны из меню приложения. Для компиляции используется ядро языка и его стандартная библиотека из проекта [ponyatny](https://github.com/ivanivorontsov-sudo/ponyatny).

## Установка и выпуск

Откройте раздел [Releases](https://github.com/ivanivorontsov-sudo/stroka-ide/releases) и скачайте актуальный APK.

GitHub Actions выполняет unit-тесты, собирает release APK для arm64-v8a и Android App Bundle, проверяет подпись и при сборке ветки `main` публикует файлы в выпуск `latest`. Отдельный workflow `Verify Android build` проверяет PR, собирает Debug APK и запускает UI-проверки сгенерированных Java- и «Понятный»-калькуляторов на Android-эмуляторе. Для версии 1.8.3 публикация выполняется только после прохождения проверок и объединения PR; до этого скачивание из Releases может вести на предыдущую версию. Workflow `Build Windows installer` доступен в Actions → Build Windows installer: он принимает GitHub Releases URL и SHA-256 portable EXE и собирает стандартный Setup.exe через Inno Setup.

## Поддержка внешних проектов

В каталоге `templates/github-actions/` находятся два шаблона: удалённая сборка Gradle multi-module/Kotlin Multiplatform на runners Linux, Windows и macOS и изолированная декомпиляция APK через JADX с выдачей artifact. Скопируйте их в `.github/workflows/` своего репозитория. После этого workflow можно запускать из встроенного экрана GitHub Actions.

- Структура Gradle multi-project/composite builds описана в официальной документации Gradle; для неё требуется запуск настоящего Gradle Wrapper и соответствующих Android/Kotlin toolchain, а не компиляция одного файла через встроенный Kotlin/JVM.
- Kotlin/Native, Kotlin/JS и Kotlin/Wasm требуют Kotlin Multiplatform toolchain и платформенных SDK. Их нельзя корректно объявить поддерживаемыми одним Android/JVM-компилятором.
- JADX изучен как кандидат для импорта APK. Авторы прямо предупреждают, что библиотека не предназначена для Android-приложений; поэтому она не включается в APK как неподтверждённая зависимость. Декомпиляция должна выполняться отдельным изолированным процессом/сборочным агентом. Даже JADX не гарантирует точного восстановления исходников; Smali и ресурсы должны оставаться доступными как резервный слой.


- Это приложение для Android; установка APK на iPhone не поддерживается.
- Подсветка синтаксиса доступна для большего числа языков, чем запуск и сборка. Локальный Kotlin пока ограничен однофайловым Android Activity; Kotlin Script, Kotlin/Native, Kotlin/JS, Kotlin/Wasm, Compose preview и полноценные multi-module Gradle проекты не исполняются локальным компилятором Строки.
- Portable Windows EXE собирается только из JavaScript и «Понятного» и предназначен для Windows x64. Стандартный Setup.exe создаётся отдельным Windows GitHub Actions workflow.
- Для голосового ввода и чата с ИИ доступность зависит от выбранного движка, установленных моделей, сети и настроек провайдера.
- Перед распространением собранного приложения проверьте его работу на целевых устройствах и соблюдение лицензий зависимостей.
