## Строка 1.9.0

- **Kotlin APK снова собирается на телефоне.** Ошибка «Не удалось запустить компилятор Kotlin: kotlin/reflect/jvm/ReflectJvmMapping» возникала потому, что в APK не попадали зависимости компилятора (kotlin-reflect, trove4j, kotlinx-collections-immutable и др.). Теперь они включены, сборка проверяется тестом на JVM и на эмуляторе Android.
- **Установщик Windows (setup.exe) прямо на телефоне:** название, версия, издатель, значок из галереи или эмодзи, ярлыки на рабочем столе и в «Пуске», запуск после установки, текст лицензии, удаление через «Приложения и возможности». Тихая установка: `/S`, папка: `/D=…`.
- **Компилятор «Понятный» 2.7.0.**
- **Новые примеры** при создании файла: короткие, с комментариями, каждый проверен (Понятный: первая программа, калькулятор, мини-игра; Java, Kotlin, Python, сайт, JavaScript, C, Godot, Atari 2600, Markdown).
- **Git:** ветки (создать/переключить), pull request на GitHub, понятные ошибки push/pull и конфликтов, пустые коммиты больше не создаются.
- **ИИ:** исправлен адрес API для Gemini и других OpenAI-совместимых серверов с версией в пути; текстовый ответ модели больше не теряется; веб-чаты распознают проверку «я не робот»; подсказка по синтаксису «Понятного» 2.7 для моделей.
